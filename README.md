# Schedule_coordination📅 모임쏙 (MoimSsok)

메신저 기반 단체 일정 조율의 구조적 비효율 해결 및 AI 최적 매칭 솔루션

AI 데이터 기반 서비스 기획 중간 과제 프로토타입 (MVP)

📌 1. 프로젝트 개요 (Project Overview)

배경 및 문제 정의 (Problem Statement)

기존 카카오톡 등 메신저 채팅방에서 단체 일정을 조율할 때 다음과 같은 구조적 비효율이 발생합니다.

텍스트 기반 피로도: 수십 개의 메시지가 범람하여 참여자별 가능 시간 파악이 어렵고 피로감이 가중됩니다.

시간 소모 및 참여자 이탈: 최종 일정 결정까지 평균 4.2일이 소요되며, 중간 참여자 이탈률이 38%에 달합니다.

주동자(리더) 부담 가중: 일정을 취합하고 재확인하는 리더의 행정적·감정적 부담으로 인해 모임 결성이 실패하는 사례가 빈번합니다.

해결 방안 (Solution)

모임쏙(MoimSsok)은 앱 설치나 회원가입 없이 웹 링크만으로 5초 이내에 참여할 수 있는 원클릭 일정 조율 및 스마트 장소 추천 웹 서비스입니다.

✨ 2. 핵심 기능 (Core Features)

① 원클릭 일정 조율 파이프라인 (CORE FEATURE 01)

3초 링크 생성: 모임명 입력만으로 즉시 공유 가능한 조율방 개설

직관적 가능 시간 선택: 모바일 환경에 최적화된 터치 방식의 타임테이블 히트맵 UI

AI 최적 매칭 추천: 참여자 데이터를 실시간 연산하여 최다 인원 및 연속 시간 가중치를 반영한 TOP 3 최적 일정 자동 산출

자동 알림 확정: 카카오톡 공유 연동 및 확정 일정 안내

캘린더 자동 동기화: 확정된 일정을 표준 iCal (.ics) 파일로 변환하여 Google / Apple 캘린더에 즉시 등록

② 앱 설치 없는 Web-based 접근성 (FEATURE 02)

카카오톡/라인 인앱 브라우저에서 회원가입이나 앱 다운로드 없이 5초 이내 즉각 참여가 가능하여 진입 장벽을 제거했습니다.

③ 스마트 중간 지점 및 장소 추천 (FEATURE 03)

참여자들의 출발지(지하철역 등) 데이터를 분석하여 평균 이동 시간이 가장 짧은 최적 환승 거점(중간 지점)을 계산합니다.

모임 성격(팀플, 식사, 카페 등)에 맞는 제휴 플레이스 추천 및 예약 연동을 지원합니다.

🚀 5. 실행 방법 (How to Run)

별도의 빌드 도구나 서버 설치 없이 웹 브라우저만으로 즉시 실행할 수 있습니다.

저장소(Repository)를 클론하거나 index.html 파일을 다운로드합니다.

Chrome, Safari, Edge 등 최신 웹 브라우저에서 index.html 파일을 엽니다.
(VS Code 사용 시 Live Server 확장 프로그램을 통해 실행 가능)

상단에서 이름과 출발역을 선택한 뒤, 타임테이블 칸을 터치하여 실시간 AI 매칭 및 캘린더(.ics) 다운로드 기능을 테스트합니다.

🗺 6. 추진 로드맵 (Execution Plan)

STAGE 01 (1~2주차) - Prompt-based PoC: 모바일 웹 기반 캘린더 인터페이스 구축 및 1차 매칭 알고리즘 검증 (현재 단계)

STAGE 02 (3~5주차) - Matching 파이프라인: 카카오톡 공유 API 연동 및 실시간 다중 사용자 응답 취합 백엔드 개발

STAGE 03 (6~8주차) - 클로즈드 베타 (CBT): 대학생 동아리 및 조별 과제 팀 100팀 대상 실전 테스트 및 피드백 수집

💼 7. 비즈니스 모델 (Business Model)

B2C 제휴 중개 수수료: 추천 맛집·카페·스터디룸 예약 연동 수수료 (3~10%)

B2B SaaS 확장: 기업 전용 워크스페이스 및 팀 일정 조율 대시보드 구독 모델
